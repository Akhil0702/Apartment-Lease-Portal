🏢 Apartment Lease Portal
A full-stack web application designed to streamline the apartment rental process. This platform provides an integrated dashboard for both landlords and renters to manage property listings, tenant applications, and secure lease agreements.

🚀 Features
Property Listings: Browse available apartments with detailed descriptions and images.

Tenant Applications: Streamlined digital application process for prospective renters.

Lease Management: Securely manage and view digital lease agreements.

Dual Dashboards: - Landlords: Manage listings, review applications, and track active leases.

Tenants: Search for homes, track application status, and access lease documents.

Real-time Status: Instant updates on apartment availability.

🛠️ Tech Stack
Backend: Python (Flask)

Frontend: HTML5, CSS3, JavaScript

Environment Management: Python Virtual Environment (venv)
)

⚙️ Installation & Setup
Clone the repository:

Bash
git clone https://github.com/Akhil0702/Apartment-Lease-Portal.git
cd Apartment-Lease-Portal
Set up the virtual environment:

Bash
# Windows
python -m venv venv
.\venv\Scripts\activate

# macOS/Linux
python3 -m venv venv
source venv/bin/activate
Install dependencies:
(Note: Ensure you have a requirements.txt file or install flask manually)

Bash
pip install flask
Run the application:

Bash
python run.py
The portal will be available at http://127.0.0.1:5000/.
